# Security Policy

This archived repository does not provide a service-level security commitment or response-time guarantee. However, security vulnerabilities in the source code are still useful to report.

Please do not disclose a vulnerability in a public issue. Instead, use GitHub's private security advisory flow for this repository and include the affected file, impact, and a minimal reproduction. Do not include credentials, personal data, or production access details in the report.

Fork operators are responsible for their own deployment security, access controls, credentials, and dependency updates.
