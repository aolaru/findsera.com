# Code of Conduct

## Our standard

Contributors and maintainers should participate in a respectful, constructive, and inclusive way. Harassment, personal attacks, discriminatory language, and sharing another person's private information are not acceptable.

## Scope

This standard applies to repository discussions, issues, pull requests, security reports, and other project-related communication.

## Reporting

Report security concerns through the private process in [SECURITY.md](SECURITY.md). For other conduct concerns, contact the repository owner privately through GitHub rather than opening a public issue.

## Enforcement

The repository owner may remove, edit, or reject contributions and restrict participation when behavior conflicts with this code of conduct.
